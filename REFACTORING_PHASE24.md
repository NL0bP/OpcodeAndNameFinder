## 🔄 Реализация

### Свойства-обертки
```csharp
public Dictionary<int, List<string>> XrefsIn
{
    get => _packetDataService.SourceXrefs[Models.PacketType.CS];
    set
    {
        _packetDataService.SourceXrefs[Models.PacketType.CS].Clear();
        if (value != null)
        {
            foreach (var kvp in value)
            {
                _packetDataService.SourceXrefs[Models.PacketType.CS][kvp.Key] = new List<string>(kvp.Value);
            }
            // Синхронизируем SC с теми же данными
            _packetDataService.SourceXrefs[Models.PacketType.SC].Clear();
            foreach (var kvp in value)
            {
                _packetDataService.SourceXrefs[Models.PacketType.SC][kvp.Key] = new List<string>(kvp.Value);
            }
        }
    }
}
```

### Маппинг
- `XrefsIn` → `SourceXrefs[PacketType.CS]` (с синхронизацией SC)
- `XrefsOut` → `DestinationXrefs[PacketType.CS]` (с синхронизацией SC)

### Методы синхронизации
- `SyncXrefsInToService()` - упрощен, синхронизирует SC с CS данными
- `SyncXrefsOutToService()` - упрощен, синхронизирует SC с CS данными

## 🔍 Особенности реализации

### Автоматическая синхронизация CS и SC
Поскольку в старом коде XrefsIn/XrefsOut не разделялись по типам пакетов, а в PacketDataService они разделены, свойство-обертка автоматически синхронизирует SC данные с CS данными при установке значения. Это обеспечивает обратную совместимость и упрощает миграцию.

### Прямой доступ к словарю
Свойство возвращает словарь напрямую из PacketDataService, что позволяет использовать его как обычный Dictionary. Это обеспечивает полную обратную совместимость с существующим кодом.
