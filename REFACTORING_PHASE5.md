## 🔄 Реализация

### Свойства-обертки
```csharp
private List<string> InListSource
{
    get => _packetDataService.SourceFileLines;
    set
    {
        _packetDataService.SourceFileLines.Clear();
        if (value != null)
        {
            _packetDataService.SourceFileLines.AddRange(value);
        }
    }
}
```
